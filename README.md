<h1>Geme requirements installer</h2>
</br>

<h2>What is it used for?</h2>
It is used to download and install sofware required for gaming. The sftware it supports are c++ Redistributable and .NET Framework Runtime.
<h2>How does it work?</h2>
Uses `BeautifulSoup` for web scraping to find the latest versions of the listed software, automaticly downloads it and runs the installer.
<h2>Requirements</h2>
- Windows 10/11</br>
- Python 3.8.0+ 
<h2>Dependencies</h2>
- requests
- beautifulsoup4

It can all be installed using a command:`pip install -r requirements.txt`
